## Описание проекта
NutriTrack — это десктопное приложение для ведения дневника питания и контроля водного баланса. 
Приложение позволяет пользователям вести учет потребляемых калорий, отслеживать выпитую воду и распознавать продукты по штрих-коду, загружая фотографии.

## Структура репозитория
Вся документация и исходный код проекта находятся в директории `NutriTrack/`:
* `NutriTrack/docs/` — проектная документация (SRS, SDD, ADR, мокапы, планы).
* `NutriTrack/src/` — исходный код приложения.

## Технологии
* Язык программирования: Java 17
* Интерфейс: Java Swing
* Сканирование штрих-кодов: ZXing
* Визуализация: JFreeChart
