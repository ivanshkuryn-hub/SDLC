## Описание проекта

NutriTrack --- локальное веб-приложение для ведения дневника питания и контроля
водного баланса.

Приложение позволяет пользователю учитывать потребляемые калории, белки,
жиры и углеводы, отслеживать количество выпитой воды и динамику массы тела,
а также находить продукты по штрих-коду с помощью загрузки фотографии.
Пользователь может просматривать графики прогресса и экспортировать дневник
питания за выбранную дату в PDF. Данные дневника, измерения веса и настройки
сохраняются локально в файлах.

Приложение запускается на компьютере пользователя как локальное веб-приложение
и предоставляет доступ к функциям через веб-интерфейс браузера.

## Основные возможности

- Ведение дневника питания с добавлением и удалением записей;
- Расчёт пищевой ценности порций и учёт калорий, белков, жиров и углеводов;
- Учёт выпитой воды с помощью быстрого и ручного ввода;
- Поиск продуктов по штрих-коду после загрузки фотографии;
- Просмотр графиков потребления калорий и воды за последние 7 дней, а также графика изменения массы тела;
- Добавление измерений массы тела с указанием даты и просмотр динамики веса;
- Экспорт дневника питания за выбранную дату в PDF;
- Настройка дневных целей по калориям и воде;
- Переключение между светлой и тёмной темами интерфейса.

Напоминания о воде, интеграция с Google Fit и другими внешними сервисами,
а также облачная синхронизация не входят в первую версию приложения.

## Технологии

- **Язык программирования:** Java 17;
- **Серверная часть:** Spring Boot, Spring MVC;
- **Шаблонизатор веб-интерфейса:** Thymeleaf;
- **Клиентская часть:** HTML, CSS, Bootstrap и JavaScript;
- **Распознавание штрих-кодов:** ZXing;
- **Визуализация данных:** JFreeChart;
- **Хранение данных:** локальные файлы CSV и Properties;
- **Сборка проекта:** Maven.

## Структура проекта

Документация и исходный код проекта размещаются в директории
`NutriTrack/`:

- `NutriTrack/docs/` --- проектная документация (SRS, SDD, ADR, планы,
  мокапы и другие материалы);
- `NutriTrack/src/main/java/by/bsuir/nutritrack/` --- исходный код
  приложения на Java;
- `NutriTrack/src/main/resources/` --- ресурсы веб-приложения, включая
  шаблоны Thymeleaf и статические файлы.

Пользовательские данные хранятся локально отдельно от ресурсов и файлов сборки:

- `products.csv` --- локальная база продуктов;
- `settings.properties` --- дневные цели и выбранная тема;
- `meals/YYYY-MM-DD.csv` --- записи дневника питания за дату;
- `water/YYYY-MM-DD.csv` --- записи учёта воды за дату;
- `weight.csv` --- история измерений массы тела.

## Запуск приложения

NutriTrack запускается как локальное веб-приложение. После запуска
серверной части пользователь открывает веб-интерфейс в браузере по адресу
`http://localhost:8080` и работает с приложением через него.

Для запуска требуется Java 17. Проект собирается с помощью Maven
в исполняемый JAR-файл. Приложение предназначено для автономной работы
и не требует подключения к интернету.
