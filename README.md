## Описание проекта

NutriTrack --- веб-приложение для ведения дневника питания и контроля
водного баланса.

Приложение позволяет пользователю учитывать потребляемые калории, белки,
жиры и углеводы, отслеживать количество выпитой воды, а также находить
продукты по штрих-коду или с помощью загрузки фотографии. Данные
дневника и пользовательские настройки сохраняются локально в файлах.

Приложение запускается как
локальное веб-приложение и предоставляет доступ к функциям через
веб-интерфейс.

## Основные возможности

-   Ведение дневника питания с добавлением и удалением записей;
-   Расчёт пищевой ценности порций и учёт калорий, белков, жиров и
    углеводов;
-   Учёт выпитой воды;
-   Поиск продуктов по штрих-коду;
-   Загрузка фотографии продукта для распознавания;
-   Просмотр статистики и графиков питания;
-   Настройка пользовательских параметров и напоминаний.

## Технологии

-   **Язык программирования:** Java 17;
-   **Серверная часть:** Spring Boot, Spring MVC;
-   **Шаблонизатор веб-интерфейса:** Thymeleaf;
-   **Распознавание штрих-кодов:** ZXing;
-   **Визуализация данных:** JFreeChart;
-   **Хранение данных:** локальные файлы CSV и Properties;
-   **Клиентская часть:** HTML, CSS и JavaScript.

## Структура проекта

Документация и исходный код проекта размещаются в директории
`NutriTrack/`:

-   `NutriTrack/docs/` --- проектная документация (SRS, SDD, ADR, мокапы
    и другие материалы);
-   `NutriTrack/src/main/java/by/bsuir/nutritrack/` --- исходный код
    приложения на Java;
-   `NutriTrack/src/main/resources/` --- ресурсы веб-приложения, включая
    шаблоны и статические файлы.

## Запуск приложения

NutriTrack запускается как локальное веб-приложение. После запуска
серверной части пользователь открывает веб-интерфейс в браузере по
локальному адресу и работает с приложением через него.

Параметры запуска и точный адрес веб-интерфейса определяются
конфигурацией проекта.
