## Описание проекта
Программа предназначена для расчета оптимального пульса во время кардиотренировок (велотренажер, эллипсоид и т.д.) для наиболее эффективного сжигания жиров. 
Расчет основывается на **формуле Карвонена**.

## Функциональные требования
- Ввод возраста и пульса в состоянии покоя (на отдельной форме).
- Валидация введенных данных (вывод сообщения об ошибке при некорректном вводе).
- Запоминание последних введенных данных в главной форме и восстановление при повторном вводе.
- Вывод целевого пульса (начального и для последующих тренировок).

## Технологии
- Язык программирования: C++ (C++ Builder)
