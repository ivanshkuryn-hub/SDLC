# Глоссарий проекта NutriTrack

| Термин | Определение |
|---|---|
| NutriTrack | Локальное веб-приложение для ведения дневника питания, учёта воды и контроля массы тела. |
| КБЖУ | Калории, белки, жиры и углеводы — показатели пищевой ценности продукта. |
| Штрих-код | Графическая информация, наносимая на упаковку товара. |
| Дневник питания | Записи о съеденных продуктах за выбранную дату. По умолчанию используется текущий день. |
| Водный баланс | Учёт количества жидкости, выпитой пользователем за определённый период. |
| Продукт | Пищевая продукция, для которой хранятся название, штрих-код и показатели пищевой ценности на 100 г. |
| Порция | Фактическое количество съеденного продукта, выраженное в граммах. |
| Локальная база продуктов | Файл products.csv, содержащий сведения о продуктах и их пищевой ценности. |
| Измерение массы тела | Запись значения массы тела пользователя с указанием даты измерения. |
| Дневная цель | Заданное пользователем целевое значение потребления калорий или воды за день. |
| График прогресса | Графическое представление динамики потребления калорий, воды или изменения массы тела. |
| Экспорт в PDF | Формирование PDF-файла с информацией о дневнике питания за выбранную дату. |
| Локальное веб-приложение | Приложение, серверная часть которого запускается на компьютере пользователя, а интерфейс открывается в браузере. |
| UI | User Interface — пользовательский интерфейс приложения. |
| SRS | Software Requirements Specification — спецификация требований к программному обеспечению. |
| SDD | Software Design Description — описание проектирования программного обеспечения. |
| ADR | Architecture Decision Record — документ, фиксирующий принятое архитектурное решение и его обоснование. |
| CSV | Comma-Separated Values — текстовый формат хранения табличных данных. |
| ZXing | Библиотека Java, используемая для распознавания штрих-кодов на загруженных изображениях. |
| JFreeChart | Библиотека Java, используемая для построения графиков. |
| Spring MVC | Технология обработки веб-запросов и организации взаимодействия контроллеров, моделей и представлений. |
| Thymeleaf | Шаблонизатор, используемый для формирования HTML-страниц на стороне сервера. |
