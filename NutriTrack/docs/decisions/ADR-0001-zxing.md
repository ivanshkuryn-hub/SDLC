# ADR-0001 — Использование библиотеки ZXing для распознавания штрих-кодов

## Статус
Принято (Accepted)

## Дата
18.11.2026

## Контекст и постановка задачи
NutriTrack должен распознавать штрих-коды продуктов по фотографии, загруженной пользователем через веб-интерфейс. Серверная часть получает изображение, обрабатывает его локально и извлекает строковое значение штрих-кода. Значение используется для поиска продукта в `products.csv`.

Требуется Java-библиотека, работающая локально, без сетевых запросов и совместимая с Java 17.

## Драйверы решения
- Работа без интернета и передачи изображений внешним сервисам.
- Поддержка распространённых форматов, включая EAN-13 и UPC.
- Обработка загруженного изображения.
- Совместимость с Java без тяжёлых нативных компонентов.
- Бесплатное использование в рамках проекта.

## Рассмотренные варианты
- **ZXing (Zebra Crossing)** — библиотека с открытым исходным кодом, реализованная на Java и поддерживающая множество форматов штрих-кодов.
- **ML Kit Barcode Scanning** — решение Google, ориентированное преимущественно на мобильные платформы и Android-экосистему.
- **Aspose.BarCode** — коммерческая библиотека с платной лицензией.

## Принятое решение
Выбрана библиотека **ZXing**. Серверная часть передаёт ей загруженное изображение для декодирования штрих-кода. Полученная строка используется компонентом поиска продуктов для обращения к локальному `products.csv`.

## Последствия
**Положительные:**
- Распознавание выполняется локально.
- Не требуется интернет или внешний API.
- Библиотека реализована на Java.
- Поддерживается широкий набор форматов.

**Ограничения:**
- Результат зависит от качества, разрешения, освещения и ориентации изображения.
- Нечёткий или повреждённый штрих-код может не распознаться.
- Необходимо обрабатывать изображения без поддерживаемого штрих-кода.

## Связь с требованиями
- `REQ-FUNC-007` — загрузка фотографии штрих-кода.
- `REQ-FUNC-008` — распознавание штрих-кода.
- `REQ-FUNC-009` — поиск продукта в локальной базе.
- `SYS-FUNC-004` — загрузка изображения.
- `SYS-FUNC-005` — распознавание штрих-кода.
