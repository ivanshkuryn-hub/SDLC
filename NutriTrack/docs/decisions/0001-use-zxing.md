# 0001 — Использование библиотеки ZXing для распознавания штрих-кодов

## Статус
Принято (Accepted)

## Контекст и постановка задачи
Для реализации функции сканирования (SYS-FUNC-005) необходимо распознавать штрих-коды (EAN-13, UPC) с загружаемых пользователем фотографий. Требуется библиотека на Java, работающая локально (без сетевых запросов) и с открытым исходным кодом.

## Драйверы решения
- Полностью бесплатная лицензия (Apache 2.0).
- Поддержка широкого спектра форматов (включая EAN-13 и QR).
- Наличие готовых методов для работы с `BufferedImage` в Java.
- Отсутствие тяжелых нативных зависимостей (работает на любой ОС).

## Рассмотренные варианты
1. **ZXing (Zebra Crossing)** — открытая, чистая Java, огромное количество примеров.
2. **ML Kit Barcode Scanning (Google)** — мощная, но требует сервисов Google Play и Android-зависимостей.
3. **Aspose.BarCode** — платная коммерческая библиотека.

## Итог решения
Выбран вариант 1 (ZXing). Он полностью закрывает потребности проекта, не требует лицензионных отчислений и не зависит от интернета.

## Последствия
**Хорошо:** Бесплатно, работает офлайн, простой API (`MultiFormatReader`), кроссплатформенность.
**Плохо:** Скорость распознавания на слабых ПК может быть чуть медленнее, чем у платных аналогов с использованием нейросетей.
