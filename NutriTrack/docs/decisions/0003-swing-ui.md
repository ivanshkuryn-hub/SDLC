# 0003 — Использование Java Swing для графического интерфейса

## Статус
Принято (Accepted)

## Контекст и постановка задачи
Необходимо разработать десктопный интерфейс для ОС Windows и Linux. Технологический стек зафиксирован: Java 17.

## Рассмотренные варианты
1. **Java Swing** — встроен в JDK, легковесный, классический подход.
2. **JavaFX** — более современный, но требует подключения внешних модулей и усложняет сборку.
3. **Веб-интерфейс (Spring Boot + HTML)** — избыточно, так как требуется локальное десктопное приложение.

## Итог решения
Выбран вариант 1 (Swing). Он не требует дополнительных зависимостей в `pom.xml`, что ускоряет сборку и упрощает запуск `.jar` на любой машине с Java.

## Последствия
**Хорошо:** Встроен в JDK, огромное количество примеров, простой запуск.
**Плохо:** Дизайн выглядит устаревшим (для "темной темы" потребуется вручную настраивать цвета компонентов).
