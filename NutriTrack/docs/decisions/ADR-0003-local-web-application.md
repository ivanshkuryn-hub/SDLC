# ADR-0003 — Локальное веб-приложение на Spring Boot, Spring MVC и Thymeleaf

## Статус
Принято (Accepted)

## Дата
18.11.2026

## Контекст и постановка задачи
NutriTrack предоставляет четыре основных экрана: главную страницу, дневник питания, сканер штрих-кодов и учёт воды. Взаимодействие выполняется через браузер на том же компьютере, где запущена серверная часть.

Приложение должно быть локальным и автономным, работать на Java 17 и поставляться в виде исполняемого JAR. Требуется выбрать технологию обработки запросов и формирования интерфейса.

## Драйверы решения
- Локальный запуск на компьютере пользователя.
- Использование Java 17.
- Формирование HTML-страниц без отдельного SPA-приложения.
- Разделение обработки запросов, бизнес-логики и доступа к данным.
- Сборка в исполняемый JAR.
- Работа без загрузки ресурсов с внешних сайтов.

## Рассмотренные варианты
- **Spring Boot + Spring MVC + Thymeleaf** — локальное Java-веб-приложение со встроенным сервером, MVC-контроллерами и серверными HTML-шаблонами.
- **Java Swing** — десктопный интерфейс, не соответствующий выбранному формату работы через браузер.
- **JavaFX** — отдельное оконное приложение.
- **SPA на отдельном JavaScript-фреймворке** — клиентское приложение с дополнительной конфигурацией сборки и взаимодействия с сервером.

## Принятое решение
Выбрано локальное веб-приложение на Java 17 с Spring Boot, Spring MVC и Thymeleaf.

Spring Boot отвечает за конфигурацию и запуск приложения со встроенным веб-сервером. Spring MVC используется для обработки HTTP-запросов. Thymeleaf формирует HTML-страницы на стороне сервера. HTML, CSS и Bootstrap используются для структуры и оформления интерфейса.

Приложение доступно по адресу `http://localhost:8080`. Статические ресурсы входят в состав приложения и не зависят от внешних CDN или сетевых сервисов. Графики JFreeChart формируются сервером в PNG и передаются браузеру через локальные HTTP-маршруты.

## Последствия
**Положительные:**
- Пользователь работает через привычный браузер.
- Серверная логика и интерфейс находятся в одном Java-проекте.
- Spring MVC разделяет контроллеры, модели и представления.
- Thymeleaf позволяет формировать страницы без отдельного SPA-клиента.
- Spring Boot упрощает локальный запуск и сборку.

**Ограничения:**
- Для работы должны быть запущены локальный сервер и браузер.
- Пользователь запускает JAR и открывает локальный адрес.
- Удалённый доступ с других устройств не входит в первую версию.
- Динамическое обновление элементов выполняется средствами веб-страниц и клиентского JavaScript в рамках выбранной архитектуры, без отдельного SPA-фреймворка.

## Связь с требованиями
- `REQ-FUNC-001`–`REQ-FUNC-014` — функциональные требования.
- `REQ-INST-001` — запуск локального приложения.
- `REQ-BUILD-001` — сборка Maven.
- `SYS-INF-001` — конфигурация и сборка приложения.
