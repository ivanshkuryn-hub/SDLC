# 0004 — Локальные напоминания через SystemTray

## Статус
Принято (Accepted)

## Контекст и постановка задачи
Приложению необходимо отправлять пользователю напоминания о воде (SYS-FUNC-009). Внешние сервисы (Email, Push) недоступны из-за ограничения автономности.

## Рассмотренные варианты
1. **SystemTray + java.util.Timer** — встроенные средства ОС для показа иконки в трее и всплывающих сообщений.
2. **Сторонние библиотеки (например, JNativeHook)** — избыточно для простых уведомлений.
3. **Email-уведомления** — противоречит ограничению автономности (нужен интернет).

## Итог решения
Выбран вариант 1. Используем `java.awt.SystemTray` для размещения иконки и `TrayIcon.displayMessage()` для показа всплывающих окон. Таймер `java.util.Timer` будет отсчитывать интервалы.

## Последствия
**Хорошо:** Работает из коробки на Windows и Linux, не требует интернета.
**Плохо:** Если пользователь выключит приложение, напоминания не придут (в отличие от мобильных ОС).
