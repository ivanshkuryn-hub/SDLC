# ADR-0004 — Отображение напоминаний о воде внутри открытого веб-интерфейса

## Статус
Принято (Accepted)

## Дата
18.11.2026

## Контекст и постановка задачи
NutriTrack должен напоминать пользователю о необходимости пить воду через заданные интервалы. Приложение работает локально в браузере, не использует внешние сервисы и не требует интернета.

Требуется выбрать механизм напоминаний, соответствующий локальной веб-архитектуре и не зависящий от системного трея операционной системы.

## Драйверы решения
- Работа без внешних сервисов и сетевых API.
- Отображение напоминания внутри интерфейса NutriTrack.
- Настройка интервала на экране «Учёт воды».
- Простота реализации в локальном веб-приложении.
- Отсутствие зависимости от SystemTray и системных уведомлений ОС.

## Рассмотренные варианты
- **Уведомления внутри веб-интерфейса** — отображение сообщения на открытой странице по истечении интервала.
- **SystemTray и уведомления ОС** — использование средств операционной системы.
- **Web Push** — доставка уведомлений через браузерную push-инфраструктуру и внешние сервисы.

## Принятое решение
Выбрано отображение напоминаний непосредственно внутри открытого веб-интерфейса NutriTrack.

Пользователь задаёт интервал на экране «Учёт воды». Значение сохраняется в `settings.properties`. Пока приложение работает и страница открыта, по истечении заданного интервала инициируется отображение сообщения в интерфейсе.

Напоминания не доставляются, если страница или браузер закрыты либо локальное приложение остановлено. SystemTray, системные уведомления ОС и Web Push в первой версии не используются.

## Последствия
**Положительные:**
- Решение соответствует локальной веб-архитектуре.
- Не требуются внешние сервисы и интернет.
- Напоминание отображается в самом приложении.
- Настройка интервала находится на экране учёта воды.
- Не требуется интеграция с системным треем.

**Ограничения:**
- Напоминания доступны только при открытой странице и работающем приложении.
- При закрытии или перезагрузке страницы клиентский таймер прекращает работу. При повторной загрузке страницы он запускается заново с интервалом, сохранённым в настройках.
- Фоновая доставка уведомлений браузером или ОС не предусматривается.

## Связь с требованиями
- `REQ-FUNC-011` — настройка интервала напоминаний.
- `REQ-FUNC-012` — отображение уведомления в веб-интерфейсе.
- `SYS-FUNC-009` — напоминания о воде.
