# Системные требования NutriTrack

**Версия:** 0.1  
**Статус:** Черновик  
**Дата:** 13.11.2026  
**Основание:** Спецификация требований к ПО `docs/srs.md`

## 1. Назначение документа

Документ содержит перечень системных требований к десктопному приложению NutriTrack, вытекающих из спецификации SRS. Определены функциональные и нефункциональные требования, их приоритеты, оценки трудоемкости и матрица трассируемости.

## 2. Шкала приоритетов

| Приоритет | Обозначение | Описание |
|---|---|---|
| 10 | Critical | Критически важное требование |
| 20 | High | Важное требование |
| 30 | Medium | Средний приоритет |
| 40 | Low | Низкий приоритет |
| 50 | Optional | Необязательное требование |
